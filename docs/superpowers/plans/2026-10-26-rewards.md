# Rewards 1 + 2: the tick moment and the "N DONE · M LEFT" count (plan, 2026-10-26)

Approved design: `.superpowers/sdd/lead-rewards-report.md` (main checkout), mockup
https://claude.ai/artifact/EXDnKT7FYfxhiyWiMdYJu8. Alex picked concepts 1 and 2 on
2026-10-26. Concept 3 (the week strip and run) and any new item field are out.

## Controller rulings (2026-10-26)

- Tick moment: plays where the row lands after the re-render; no code holds the reorder.
  Respects `prefers-reduced-motion`. Plays on Today and on To-do.
- Count: counts only rows in Overdue and To do today (the struck rows on screen); a to-do
  finished early, dated later, does not count. Hidden until the first tick of the day.
  "ALL N DONE" only when both sections are fully ticked.

## Task 1: the count (concept 2)

- `js/today.js`: pure `tally(today)` over a `buildToday` result. `done` = rows of
  `overdue` + `todo` whose item is `done === true`; `left` = the rest. Returns `null` when
  `done === 0` (hidden until the first tick), else `{ done, left }`. It reads the rows, so
  it is the struck rows on screen by construction, with `tickedToday`'s accepted cost.
- `js/todayview.js`: `renderTally(node, tally)`. `null` -> node empty and `hidden`.
  `left === 0` -> `<b>All N done</b>`. Otherwise `<b>N done</b><span> · </span>
  <span class="today-tally-left">M left</span>`. Upper case comes from CSS.
- `index.html`: `<p id="today-tally" class="today-tally" hidden></p>` as the second child
  of `.today-head` (already `justify-content: space-between`).
- `js/app.js`: `els.todayTally`; `renderToday` calls `renderTally(els.todayTally, tally(today))`.
- `styles.css`: the mockup's `.mk-tally` rules renamed `.today-tally`, `.today-tally b`,
  `.today-tally-left`.
- Tests: `today.test.js` (TZ pinned): no ticks -> null; 2 of 5 -> {2, 3}; a ticked overdue
  counts done; an item ticked yesterday (overdue, so not on screen) counts in neither; a
  done to-do dated later counts in neither; all ticked but one overdue -> left 1.
  `todayview.test.js`: the drawn text and `hidden` for each case, and a re-render empties
  the node. `apply.test.js`: through the real app, hidden before a tick, "1 done · 1 left"
  after one, "All 2 done" after both, hidden again after unticking. `styles.test.js`: the
  tally CSS.

## Task 2: the tick moment (concept 1)

- `js/app.js`: module `justTicked = null`. `handleToggleDone`, after `setDone` saves and
  only when `done === true`, sets it to the id for the one `render()` that follows, and
  clears it in a `finally`. A failed save and an untick never set it. `renderToday` and
  `renderTodos` pass it as `justTicked`. Every later render (sync, tab switch) has none.
- `js/todayview.js` / `js/todoview.js`: option `justTicked` (null or a string; anything
  else throws). The row whose item has that id and is `done === true` gets class
  `tick-just`, and its title text is wrapped in `<span class="tick-strike">`, so the strike
  can be drawn across the text only. (The mockup drew it as a background on
  `.today-text`, which is `flex: 1`: the line ran past the title to the meta, and it would
  jump to the text width on the next render.)
- `styles.css`: `--tick-glow` in `:root` and `[data-theme="dark"]` (the mockup's values).
  All tick rules inside `@media (prefers-reduced-motion: no-preference)`, so Reduce Motion
  sees exactly today's page: a wash (inset box-shadow fading out, which also suits the
  To-do page's card rows, where a background-colour animation would end on transparent
  instead of the card), a 260 ms pop of the box, and the strike drawn left to right in
  320 ms; `text-decoration: none` on the just row's title so the drawn line replaces the
  line-through. Keyframes `tick-wash`, `tick-pop`, `tick-draw`.
- Tests: `todayview.test.js` / `todoview` tests in `v6views.test.js` or a new block: only
  the row with the id gets the class and the strike span; no id -> none; an undone row with
  the id -> none; a bad `justTicked` throws. `apply.test.js`: a tick on Today and on To-do
  draws `tick-just` on that row; the next render (a tab switch) draws none; an untick draws
  none; a failed save draws none. `styles.test.js`: replace "the stylesheet declares no
  motion yet" with "every animation is inside a reduced-motion no-preference block", plus
  the token in both themes and the specificity of the `text-decoration: none` override.
